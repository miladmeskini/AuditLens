# AuditLens

# 

# AuditLens is a professional-grade forensic analytics platform developed to automate the detection of financial anomalies and potential misstatements in large datasets. Built for efficiency and accuracy, this tool empowers financial analysts to identify irregularities through advanced statistical methods.

# 

# Key Features

# Forensic Validation: Implements Benford’s Law analysis and chi-square statistical testing to quantify financial risk scores.

# Real-Time Visualization: Features a modular UI with Matplotlib-integrated dashboards, allowing for immediate review of MAD (Mean Absolute Deviation) scores and risk component breakdowns.

# Automated Workflow: Streamlines audit preparation by automating data cleaning and sequential numbering detection, significantly reducing manual effort during financial reviews.

# 

# Built WithPython  PySide6 (for the modular user interface)  Matplotlib (for interactive risk visualization)
